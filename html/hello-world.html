Welcome to my blog. This is the first post, and it mostly exists so the index isn't empty.

How this blog works

Every post is a Markdown file in this repository. When I push a change to main, a GitHub Action reads each post's front matter and rebuilds index.json. My portfolio site fetches that file and shows the list of posts.

What to expect

I plan to write about the projects I build, things I learn along the way, and the tools I use every day.
